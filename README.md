# Game Roster Organizer 
- It helps keep on track of who is on the roster and who has confirmed or not.

The project seems to be useful because it is really simple and easy to use 
and it helps to keep on track of who has confirmed for a roster list.
It can be used for a lot of different situations: A soccer game, a dinner, a trip...

To run the program, go inside the folder to_dont_list, make sure
that pubspec is inside and in the terminal run "flutter pub get" 
to download and solve all packages listed in pubspec,
and then run "flutter run" in the terminal.
